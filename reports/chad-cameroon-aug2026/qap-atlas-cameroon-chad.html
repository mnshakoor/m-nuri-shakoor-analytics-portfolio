ADMIN1 Conflict Atlas, Where the mechanisms diverge

This is a boundary-backed geographic atlas. Real country outlines anchor each ADMIN1 observation in its geographic context, while source centroids carry the conflict measures. Switch layers to compare event burden, fatalities, abduction, mob violence, air/drone activity and coercive share.

Scope boundary. The primary comparison uses 34 matched weekly observations: 4 Jan to 23 Aug 2025 and 3 Jan to 29 Aug 2026. The workbook contains weekly aggregated category-geography records, not raw narrative event reports. Population exposure is missing in 2,129 of 7,598 rows and is not imputed or used in the core statistical battery. All real-world events after 29 Aug 2026 post-date this evidence base.

03 // METHOD

Cartographic choices

DecisionChoiceReason
ProjectionPrecomputed MercatorBoundary paths and ADMIN1 centroids are projected before publication, so the HTML requires no runtime mapping library.
GeometryReal country outlines plus sourced ADMIN1 centroidsThe workbook contains ADMIN1 point coordinates but not administrative polygons. Country boundaries provide real geographic context without pretending that centroid markers are region shapes.
MagnitudeBubble areaGeographic position identifies the ADMIN1 unit; marker area carries the selected quantity.
CountryGold / blue category colourColour remains categorical. Quantity is encoded by position and marker area.

04 // LIMITS

Map precision has a defined boundary

ADMIN1 geometry

Markers represent source centroids. They do not imply that events occurred at the centroid or that risk is uniform across the administrative region.

Scale

Marker area is normalized within each layer and should not be compared across different layers.

Boundary context

Country outlines are cartographic context only. The display makes no claim about disputed boundaries or territorial status.

05 // SOURCES

Shared data spine

The atlas reads the same verified 2026 ADMIN1 layer used by the data story. ADMIN1 coordinates and event counts come from the supplied workbook; shares are derived. Country outline geometry is embedded from the CountryInfo 0.1.2 package data, maintained by Porimol Chandro under the MIT License, and is used only as cartographic context. The portfolio source register records this added boundary-context source and its limitation.
